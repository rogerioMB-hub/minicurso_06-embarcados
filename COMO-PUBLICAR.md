# Como publicar este minicurso

## 1. Criar o repositório

1. No GitHub, crie o repositório **`minicurso_06-embarcados`** (público).
2. Arraste todos os arquivos e pastas deste pacote para a página do repositório (*Add file → Upload files*).
3. Faça o commit.

## 2. Ativar o GitHub Pages

1. *Settings → Pages*.
2. Em **Source**, escolha *Deploy from a branch*.
3. Branch **`main`**, pasta **`/ (root)`** → *Save*.
4. Aguarde 1–2 minutos. O site fica em:
   `https://rogeriomb-hub.github.io/minicurso_06-embarcados/`

## 3. Google Sites

O Google Sites bloqueia o GitHub em iframe. Use **botões** que abrem o link em nova aba.

## 4. Atualizações

- Arraste apenas os arquivos novos ou alterados.
- Mensagem de commit no padrão: `feat(aulaXX): descrição`.
- Links da tabela do `index.md` sempre com **URL absoluta** (o tema Cayman não aplica o `baseurl` em links Markdown).
